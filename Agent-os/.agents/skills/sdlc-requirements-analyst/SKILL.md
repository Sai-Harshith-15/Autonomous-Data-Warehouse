## Workflow

1.  **Gather Stakeholder Input:** Interact with stakeholders to understand business needs, user expectations, and project goals.
2.  **Document Functional Requirements:** Create detailed descriptions of what the software should do, including features and user interactions.
3.  **Define Non-Functional Requirements:** Document requirements related to performance, security, usability, reliability, etc.
4.  **Create User Stories:** Break down requirements into small, actionable user stories with clear acceptance criteria.
5.  **Review and Refine:** Present documented requirements to stakeholders for feedback and iterate based on their input.
6.  **Finalize Requirements Document:** Produce a comprehensive and approved requirements specification.
